Hi there! I'm **Samuel**, a 26-year-old cybersecurity student at **La Plateforme** in Marseille, on a work-study program at **Softway Medical** as an integration & support technician.

I'm also an independent beatmaker, releasing music as **D SAM**, and I shoot photos whenever I travel. I'm used to learning by myself and I love discovering new things. Two worlds, one mindset: break it down, understand it, rebuild it better.

<p align="center">
  <img src="assets/section-02-lab.svg" alt="02 — Security lab" width="100%">
</p>

- **Currently working on Nessus** — vulnerability scanning, and learning to read, prioritize and report findings
- **Virtualization** — nested labs and VM migrations between type 1 hypervisors (ESXi, Hyper-V, Proxmox VE, XCP-ng)
- **Containers & orchestration** — Docker, Docker Swarm (HA cluster with NFS storage), K3S / Kubernetes with Helm
- **Infrastructure as Code** — Terraform to deploy attacker/victim VM labs, Ansible for hardening, Suricata, Filebeat and Vault
- **Identity & compliance** — Microsoft Entra ID (PowerShell, Graph, SAML SSO) and a GDPR audit with the CNIL PIA tool
- **Networking** — DHCP, SSH, FTP, LDAP, VoIP, Wireshark, Linux administration
- **Hardware** — learning to build PCs from the ground up
